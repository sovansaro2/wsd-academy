# WSD Academy Project Rules

## UI & Iconography Guidelines

1. **No AI Sparkle / Star Icons (`Sparkles`, `Sparkle`, `Wand`, `Wand2`, `✨`)**
   - Do **not** use `Sparkles`, `Sparkle`, `Wand`, `Wand2`, or star/sparkle emojis (`✨`) anywhere in the UI (buttons, section headers, tiles, banners, or badges).
   - Use literal, domain-specific icons instead (e.g., `Clock` for recent/latest items, `Eraser` / `Trash2` / `HardDrive` for storage cleanup, `BookOpen` / `Library` for textbooks).
2. **Data Integrity & Branding**
   - Display only real platform data and existing features. Do not fabricate metrics, counters, or AI branding.
